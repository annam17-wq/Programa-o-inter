Sobre git

Sobre git discutimos o funcionamento do git, o que é o workcopy, stage, commit, repositório. Os comandos git utilizados são listados abaixo

  • git init | cria um repositório git vazio .git
  • git status | exibe estado do rep.
  • git add | adiciona no stage
  • git log | lista o commits da branch(ramo) atual
  • git checkout branch | recupera wk a partir de um branch
