A linguagem utilizada na comunicação entre cliente e servidor é o que chamamos de protocolo, no caso da web o HTTP.

HTTP é o "idioma" que permite que o seu navegador (cliente) e os computadores que hospedam os sites (servidores) conversem entre si para carregar páginas da internet.

- Quando um cliente faz uma solicitação a um servidor é enviada uma mensagem HTTP pela portas 80 ou 443 (Request).

- O servidor então processa a mensagem e gera um texto de retorno (Response).
